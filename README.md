# オーブ手帳

モンスターストライクのオーブ計画を手入力で整理する、非公式ファン向けプロトタイプです。

## 現在の機能

- オーブ数、ランク、所持キャラ、狙いキャラ名を入力
- ゲーム内の「提供割合」を入力して、指定回数で1体以上引ける確率を試算
- 期限、キープしたいオーブ数、手動登録した回収予定からガチャ計画を確認
- 回収予定に公式告知のリンクを保存
- 入力データは利用中の端末のブラウザー内に保存

確率は、各回の抽選が独立し、入力した提供割合が毎回同じという前提の計算です。結果は当選を保証しません。アドバイスは入力値にもとづくルールベースで、生成AIには接続していません。

## 開発

```sh
npm install
npm run dev
```

本番用ビルドとランタイム確認:

```sh
npm run build
```

## データと情報の扱い

スクレイピングは行いません。ガチャ確率とオーブ回収予定は利用者が入力し、告知は公式ページへのリンクとして登録します。記事本文や画像はアプリ内に転載しません。入力データはブラウザーの `localStorage` に保存されます。

このアプリは株式会社MIXIおよびモンスターストライクの公式アプリではありません。
